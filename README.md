# OWNVER — Magnetic Leather Hat Piece

OWNVER 可替換磁吸皮革帽飾品牌網站。

**Own Every Version.**  
擁有每一個版本的自己。

## 目前版本

- 繁體中文 / English 切換
- 手機與桌面響應式版面
- 3–8 個英文字母即時皮件預覽
- 可持續擴充的故事影片牆（目前預留 20 部）
- 手機左右滑動、桌面橫向瀏覽
- 影片彈出播放與故事文字
- 原生分享功能
- Pinkoi 導購入口（目前為待設定狀態）

## 後續加入影片

在 `script.js` 的 `storyVideos` 資料中填入影片路徑；影片檔可放在 `assets/videos/`。每則故事可設定皮革文字、簡介、封面與影片，數量也能繼續增加。

Pinkoi 正式上架後，在 `index.html` 找到 `id="pinkoi"`，把 `href="#"` 換成商品網址即可。
